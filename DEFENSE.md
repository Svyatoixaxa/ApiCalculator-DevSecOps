# План защиты API Calculator — DevSecOps

## 1. Цель и архитектура

Разработан REST API калькулятора на Python 3.13 и FastAPI. Docker обеспечивает воспроизводимый запуск, GitHub Actions — тестирование, сборку, версионирование и проверку безопасности при push. Semgrep анализирует исходный код и конфигурацию (SAST), Trivy — компоненты контейнера (SCA).

## 2. Демонстрация (5–7 минут)

1. Открыть [репозиторий](https://github.com/Svyatoixaxa/ApiCalculator-DevSecOps). Показать main.py: шесть операций, FiniteFloat, обработку деления на ноль и переполнения, /version.
2. Показать Dockerfile: FROM python:3.13-slim, ARG/ENV APP_VERSION, установка зависимостей, USER 10001:10001, CMD запуска Uvicorn.
3. Показать .github/workflows/ci.yml: push и workflow_dispatch, версия 1.0.N, закрепление Actions по SHA, две задачи, выгрузка отчетов.
4. Открыть [запуск №16](https://github.com/Svyatoixaxa/ApiCalculator-DevSecOps/actions/runs/45557243979) (автоматический push) и [№17](https://github.com/Svyatoixaxa/ApiCalculator-DevSecOps/actions/runs/45557482878) (ручной). Открыть Install and test и Run and check container: шесть групп тестов, версия 1.0.17, результат 5.0, проверка UID.
5. Открыть Run Semgrep и Run Trivy. Показать артефакты semgrep-17-1, trivy-17-1 и calculator-api-17-1. Последний артефакт хранится 14 дней; для демонстрации позже его можно собрать повторно.
6. Показать SECURITY_ANALYSIS.md: результаты, отличие фильтров и рекомендации. Не утверждать, что уязвимости устранены полностью.

## 3. Локальная демонстрация при наличии Docker

```powershell
docker build --pull --build-arg APP_VERSION=1.0.0 -t calculator-api:1.0.0 .
docker run -d --name calculator-container -p 127.0.0.1:8000:8000 calculator-api:1.0.0
curl.exe "http://127.0.0.1:8000/add?a=2&b=3"
curl.exe "http://127.0.0.1:8000/version"
curl.exe -i "http://127.0.0.1:8000/divide?a=5&b=0"
docker exec calculator-container id
```

Swagger: http://127.0.0.1:8000/docs. Ожидаемые ответы: 5.0, версия 1.0.0, HTTP 400 при делении на ноль; UID 10001. После демонстрации: `docker rm -f calculator-container`. Локальная демонстрация требует Docker; фактически проверенный запуск выполнен в GitHub Actions.

## 4. Вопросы преподавателя

| Вопрос | Ответ |
|---|---|
| Что такое API? | Интерфейс взаимодействия программ: запрос HTTP GET, параметры a и b, ответ JSON. |
| Чем FastAPI отличается от Uvicorn? | FastAPI — фреймворк API, Uvicorn — ASGI-сервер, который принимает HTTP-запросы. |
| Что такое Docker-образ и контейнер? | Образ — шаблон файловой системы и запуска; контейнер — экземпляр образа. |
| Зачем непривилегированный USER? | Уменьшает последствия компрометации процесса приложения. |
| Что такое CI/CD и DevSecOps? | Автоматизация интеграции и доставки, с встроенными проверками безопасности. Постоянный деплой здесь не настроен. |
| Как обновляется версия? | Номер запуска github.run_number передается как APP_VERSION при сборке Docker. Push запускает workflow автоматически. |
| Что делает Semgrep? | Статически проверяет код и конфигурацию по правилам. В запуске №17: 330 правил, 10 файлов, 4 находки. |
| Что делает Trivy? | Сопоставляет версии компонентов образа с базой уязвимостей. В №17: 53 HIGH в ОС, 5 HIGH в Python, 0 CRITICAL. |
| Почему пайплайн зеленый при наличии находок? | Отчетный режим: находки не блокируют сборку, ошибки исполнения блокируют. |
| Почему выросло число находок Trivy? | Убрали ignore-unfixed, изменились база и версия Debian. 58 записей не означают 58 уникальных CVE. |
| Как устранить замечания Semgrep? | Cooldown для Dependabot, разбор JSON из файла вместо конвейера curl в Python; последнее предупреждение потенциально ложное в данном контексте. |
| Как устранять CVE? | Проверить происхождение пакетов, применимость, обновить или исключить их, пересобрать образ и повторить анализ. |
| Что подтверждает тестирование? | Корректность шести операций, обработку ошибочного ввода и математических ошибок, наличие документации и версии. Нагрузочное тестирование не проводилось. |

## 5. Вывод

Функциональность API, сборка и запуск Docker-контейнера, автоматический запуск CI и работа сканеров подтверждены успешными запусками. Обнаруженные уязвимости и меры снижения рисков задокументированы; полное устранение всех находок не заявлено.
